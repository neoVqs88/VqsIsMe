> **定义统一采用**（最常用形式）：
> 
$$
> \mathcal{F}\{f(t)\} = F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-j\omega t} dt
>
$$

> 
$$
> \mathcal{F}^{-1}\{F(\omega)\} = f(t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{j\omega t} d\omega
>
$$

#### 周期信号从傅里叶变换写出傅里叶级数的方法

1. 写出信号的傅里叶变换 X(jω)（允许冲激），利用已知变换对和性质。
2. X(jω) 一定形如 ∑ A_k δ(ω - kω₀)，其中 ω₀ = 2π/T。
3. 直接读出每个冲激的强度 A_k。
4. 傅里叶级数系数 c_k = A_k / (2π)。

##### 为什么除以 2π？
因为傅里叶逆变换：
$x(t) = (1/(2π)) ∫ X(jω) e^{jωt} dω$
代入 $X(jω) = 2π ∑ c_k δ(ω - kω₀)$ 得：
$x(t) = ∑ c_k e^{jkω₀ t}$
所以已知 $A_k$（冲激强度）时，$c_k = A_k / (2π)$。

举例：$x(t) = cos(ω₀ t)$
    $X(jω) = π[δ(ω-ω₀) + δ(ω+ω₀)]$
    $A₁ = π,  A₋₁ = π$
    $c₁ = π/(2π) = 1/2,  c₋₁ = 1/2$

## 一、基础

| 时域 $f(t)$            | 频域 $F(\omega)$                                                  | 备注     | 证明方法                    |
| -------------------- | --------------------------------------------------------------- | ------ | ----------------------- |
| $\delta(t)$          | $1$                                                             | 单位冲激   |                         |
| $\delta(t - t_0)$    | $e^{-j\omega t_0}$                                              | 时移性质   |                         |
| $1$                  | $2\pi \delta(\omega)$                                           | 常数信号   |                         |
| $e^{j\omega_0 t}$    | $2\pi \delta(\omega - \omega_0)$                                | 复指数    |                         |
| $\cos(\omega_0 t)$   | $\pi [\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$   | 余弦     |                         |
| $\sin(\omega_0 t)$   | $-j\pi [\delta(\omega - \omega_0) - \delta(\omega + \omega_0)]$ | 正弦     |                         |
| $e^{-at} u(t)$       | $\frac{1}{j\omega + a}$                                         | 单边指数信号 | 前提是a>0，所以趋于0的极限≠F{u(0)} |
| $e^{-a\|t\|}$        | $\frac{2a}{a^2 + \omega ^2}$                                    | 双边指数信号 |                         |
| $u(t)$               | $\pi \delta(\omega) + \frac {1} {j \omega}$                     |        | $u(t)-u(-t)=sgn(t)$     |
| $sgn(t)$             | $\frac {2} {j \omega}$                                          |        | 频移微分性质                  |
| $\frac {sin(t)} {t}$ |                                                                 |        |                         |
| $rect(t)$            | $\frac {sin(\frac {\omega} {2})} {\frac {\omega} {2}}$          |        |                         |
| $\frac {1} {t}$      | $-j\pi sgn(\omega)$                                             |        |                         |
| $1-\|x\|$            | $\frac {sin^2(\omega /2)} {(\omega /2)^2}$                      |        | 三角窗函数是矩形函数和自身的卷积        |

## 二、逆变换常用（解你这种题的核心）

| 频域 $F(\omega)$ | 时域 $f(t)$ |
|--------------------|---------------|
| $e^{j a \omega}$ | $\delta(t + a)$ |
| $e^{-j a \omega}$ | $\delta(t - a)$ |
| $\cos(a\omega)$ | $\frac12 [\delta(t+a) + \delta(t-a)]$ |
| $\sin(a\omega)$ | $\frac{1}{2j} [\delta(t+a) - \delta(t-a)]$ |

> ⚠️ **注意**：这是逆变换直接对，不含 $2\pi$，因为逆变换定义中已含 $\frac{1}{2\pi}$。

## 三、常用性质（快速推导用）

| 性质 | 公式 |
|------|------|
| 线性 | $af(t) + bg(t) \leftrightarrow aF(\omega) + bG(\omega)$ |
| 时移 | $f(t - t_0) \leftrightarrow e^{-j\omega t_0} F(\omega)$ |
| 频移 | $e^{j\omega_0 t} f(t) \leftrightarrow F(\omega - \omega_0)$ |
| 时域微分 | $f'(t) \leftrightarrow j\omega F(\omega)$ |
| 频域微分 | $-jt f(t) \leftrightarrow F'(\omega)$ |
| 卷积（时域） | $(f * g)(t) \leftrightarrow F(\omega) G(\omega)$ |
| 卷积（频域） | $f(t) g(t) \leftrightarrow \frac{1}{2\pi} (F * G)(\omega)$ |
| 对偶性 | 若 $f(t) \leftrightarrow F(\omega)$，则 $F(t) \leftrightarrow 2\pi f(-\omega)$ |

## 四、记忆技巧

1. **对称性**：时域的 δ ↔ 频域的常数（带 $2\pi$ 因子）；
2. **指数信号**：时域 $e^{j\omega_0 t}$ ↔ 频域 δ 在 $\omega_0$；
3. **逆变换的特殊情况**：$e^{j a\omega}$ ↔ $\delta(t + a)$ 直接对应，不需要 $2\pi$；
4. **sinc ↔ rect** 对偶关系非常重要，经常互考。
