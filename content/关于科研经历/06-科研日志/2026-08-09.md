## 🤔 今天的困惑 / 你学到了什么？

1. 如何筛选文件上传，而非“全量打包”

>    fMRIprep 生成了几千个文件（结构像、混淆矩阵、报告），我只想把最终在 MNI 空间预处理好的功能像（`*_space-MNI152NLin2009cAsym_res-2_desc-preproc_bold.nii.gz`）传到服务器，但不想动其他文件，怎么做到？


在 `rsync` 中，`--include` 和 `--exclude` 的**顺序**决定上传的文件。具体而言，一个命令可以这么写：
```bash
rsync -avz \
--include='*/' \                    # 第1层：放行所有文件夹（否则进不去子目录）
--include='sub-01/ses-*/func/*_space-MNI152NLin2009cAsym_res-2_desc-preproc_bold.nii.gz' \  # 第2层：只精准留住目标文件
--exclude='*' \                     # 第3层：丢弃其他所有东西
源路径/  user@IP:目标路径/
```
**注意**：`rsync` 不按**名字**过滤，而是按**规则队列**过滤。
		`--include='*/'` 必须写在 `--exclude='*'` 前面，否则连文件夹都被排除，后面的精确匹配读不到。

2. 注意上传文件时的端口

>    报了 `ssh: connect to host port 22: Connection refused`，明明 IP 和密码都对，就是连不上。

**学到的指令（指定端口传输）**：
服务器的端口不一定是默认的22端口，对于本实验则是`32222`端口。
普通的 `scp` 或 `rsync` 不会自动探测，必须通过 `-e` 参数改变传输端口。

```bash
rsync -avz -e "ssh -p 32222" \      # -e 代表 "使用后面的命令连接"，强行指定 32222 端口
--include='*/' \
--include='子目录/目标文件.nii.gz' \
--exclude='*' \
源路径/  用户名@IP:/目标路径/
```
**注意**：无论 `ssh`、`scp` 还是 `rsync`， `Connection refused`错误指向你应该注意真正的端口号，然后加 `-p 端口号`（ssh/scp）或 `-e "ssh -p 端口号"`（rsync）。

3. `rsync error: code 23` 不等于“传输失败”（极其重要）

>    传输数据完毕后，报错 `rsync error: some files/attrs were not transferred (code 23)`

**指令解析**：
- `rsync` 默认会带 `-a`（归档模式），它会试图同步**文件夹本身的修改时间**。
- 我的服务器账户没有权限修改该父目录的系统属性（可能是 root 创建的）。
- **但是**不影响文件夹内部的 `.nii.gz` 数据块写入。

**验证指令（学会事后检查）**：
登录服务器后，我使用这条命令清点了文件数量，确认 60 个 Session 都在：

4. 如何生成 **丘脑 / SMN** 部分的 mask？

为了精细定位对应位置，使用更高精细度的预处理结果是必要的。这里使用配准到 ***MNI152NLin2009cAsym***标准空间，分辨率为2mm的预处理结果。

首先，针对这个标准空间，我选取了图谱***Melbourne Subcortex Atlas***。
下载图谱之后解压可以发现：

>    [hanlabundergrad2@bcm Tian2020MSA]$ ls
>    3T  7T  license.txt  README.txt

根据不同的磁场强度应当选择不同的文件。查阅我们的元数据，可以得知我们的数据磁场强度为 3T。选取 3T 磁场强度，可以发现：

>    [hanlabundergrad2@bcm 3T]$ ls
>    Cortex-Subcortex  README.txt  Subcortex-Only

我们要做的 mask 是**丘脑**（皮层下），和 **SMN网络** （皮层功能），因此我们需要使用***Cortex-Subcortex***。进入*Cortex-Subcortex/MNIvolumetric/* 即可。

对应位于 *Cortex-Subcortex* 处的 label 文件，我们可以了解 SMN 网络和 丘脑核团 对应的位置，执行以下指令：

~~~
# 1. 进入正确的文件夹
cd /home/hanlabundergrad2/Atlas/Tian2020MSA/3T/Cortex-Subcortex/MNIvolumetric/

# 2. 定义输入文件名
input_file="Schaefer2018_200Parcels_7Networks_order_Tian_Subcortex_S1_3T_MNI152NLin2009cAsym_2mm.nii.gz"

# ================== 制作丘脑 Mask ==================
echo "正在制作丘脑 Mask..."
# 提取右侧丘脑（标签 3 和 4）
fslmaths $input_file -thr 3 -uthr 4 -bin temp_thal_rh.nii.gz
# 提取左侧丘脑（标签 11 和 12）
fslmaths $input_file -thr 11 -uthr 12 -bin temp_thal_lh.nii.gz
# 左右合并
fslmaths temp_thal_rh.nii.gz -add temp_thal_lh.nii.gz -bin Thalamus_Mask_S1.nii.gz

# ================== 制作 SMN Mask ==================
echo "正在制作 SMN Mask..."
# 提取左侧 SMN（标签 31 到 46）
fslmaths $input_file -thr 31 -uthr 46 -bin temp_smn_lh.nii.gz
# 提取右侧 SMN（标签 132 到 150）
fslmaths $input_file -thr 132 -uthr 150 -bin temp_smn_rh.nii.gz
# 左右合并
fslmaths temp_smn_lh.nii.gz -add temp_smn_rh.nii.gz -bin SMN_Mask_S1.nii.gz

# ================== 清理临时文件 ==================
rm temp_*.nii.gz

# ================== 验证完成 ==================
echo "制作完成！当前目录下的Mask文件有："
ls -lh *Mask*.nii.gz
~~~

 5. 如何根据 **丘脑 / SMN** 部分的 mask 提取信号？
~~~
# 1. 进入 derivatives 目录
cd /home/hanlabundergrad2/Downloads/28AndMe/ds002674-1.0.6/derivatives

# 2. 创建目录结构
mkdir -p FC_Analysis/masks
mkdir -p FC_Analysis/timeseries
mkdir -p FC_Analysis/results

# 3. 把做好的两个Mask复制到分析目录下（方便调用）
cp /home/hanlabundergrad2/Atlas/Tian2020MSA/3T/Cortex-Subcortex/MNIvolumetric/Thalamus_Mask_S1.nii.gz FC_Analysis/masks/
cp /home/hanlabundergrad2/Atlas/Tian2020MSA/3T/Cortex-Subcortex/MNIvolumetric/SMN_Mask_S1.nii.gz FC_Analysis/masks/
~~~

复制完毕之后，我执行了指令：

~~~
# 设定路径变量，方便书写
base_dir="/home/hanlabundergrad2/Downloads/28AndMe/ds002674-1.0.6/derivatives"
mask_dir="$base_dir/FC_Analysis/masks"
out_dir="$base_dir/FC_Analysis/timeseries"

# 循环从 01 到 60
for ses in $(seq -f "%02g" 1 60); do
    echo "正在处理 session ${ses} ..."
    
    # 定义输入功能像路径
    input_file="$base_dir/fmriprep2/sub-01/ses-${ses}/func/sub-01_ses-${ses}_task-rest_space-MNI152NLin2009cAsym_res-2_desc-preproc_bold.nii.gz"
    
    # 检查文件是否存在，避免报错中断
    if [ -f "$input_file" ]; then
        # 提取丘脑信号
        fslmeants -i "$input_file" -o "$out_dir/sub-01_ses-${ses}_thalamus.txt" -m "$mask_dir/Thalamus_Mask_S1.nii.gz"
        # 提取SMN信号
        fslmeants -i "$input_file" -o "$out_dir/sub-01_ses-${ses}_SMN.txt" -m "$mask_dir/SMN_Mask_S1.nii.gz"
    else
        echo "警告: 找不到 $input_file，已跳过"
    fi
done

echo "所有session处理完毕！"
~~~
