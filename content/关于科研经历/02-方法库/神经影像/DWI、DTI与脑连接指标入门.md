## 适用范围

用于阅读或开展以扩散 MRI 和静息态 fMRI 研究脑区间连接的工作。本文区分数据、模型和指标，避免将 tractography 结果、白质微结构指标与真实神经纤维数量混为一谈。

## 从 DWI 到 DTI

```text
DWI 原始或预处理图像
  + bval / bvec / JSON 元数据
        -> 扩散模型拟合（DTI 是其中一种）
        -> FA、MD、AD、RD、主扩散方向等衍生物
        -> 可进一步进行概率纤维追踪
```

- **DWI（diffusion-weighted imaging）**：扩散加权成像数据。通过在多个方向和扩散加权强度下采集 MRI，反映水分子扩散受组织微结构限制的情况。BIDS 项目中的 `dwi/` 目录通常保存 DWI 数据与其元数据，不代表 DTI 指标已经完成计算。
- **bval**：每个 volume 的扩散加权强度。`b=0` 是几乎未加扩散权重的基线图像；较高 b 值对扩散更敏感。
- **bvec**：每个扩散加权 volume 对应的梯度方向。
- **DTI（diffusion tensor imaging）**：对 DWI 拟合单张量扩散模型。它估计每个体素内水分子主要扩散方向及其方向性，适用于方向相对一致的白质区域。

典型 DWI 文件包括：

```text
sub-01_dwi.nii.gz  # 四维扩散图像
sub-01_dwi.bval    # b 值
sub-01_dwi.bvec    # 梯度方向
sub-01_dwi.json    # 采集元数据
```

## 常见 DTI 指标

- **FA（fractional anisotropy，分数各向异性）**：扩散是否集中在某一方向的指标，通常介于 0 和 1。较高 FA 可见于纤维走向较一致的白质，但不应直接称为“更多纤维”“更强连接”或“更健康”。
- **MD（mean diffusivity）**：平均扩散率，描述总体扩散程度。
- **AD（axial diffusivity）**：沿主扩散方向的扩散率。
- **RD（radial diffusivity）**：垂直于主扩散方向的扩散率。

一个体素包含多束交叉、分叉或扇形展开的纤维时，单张量模型难以充分表达其复杂性。此时 FA 变化可以源于纤维几何结构，而不一定代表白质完整性变化。

## 结构连接与概率纤维追踪

- **结构连接（structural connectivity, SC）**：基于白质通路估计的脑区间解剖连接。它是通路存在和范围的间接估计，不是轴突计数，也不证明信息传递方向或因果影响。
- **ROI（region of interest）**：预先定义的感兴趣脑区。
- **分区（parcellation）**：依据连接模式或其他特征，将一个 ROI 划为多个子区。例如，将楔前叶中最倾向连接丘脑的体素归入“丘脑相关分区”。
- **概率纤维追踪（probabilistic tractography）**：根据扩散方向模型从种子区生成大量可能路径，并估计这些路径到达目标区的可能性。它不会直接观察神经纤维。

研究中的“连接范围”（extent of structural connectivity）常指符合预设概率阈值的追踪连接汇总值。它只适合在相同采集、预处理、追踪参数、ROI 与加权策略下作相对比较。

若使用**距离校正**，通常是为了缓解近距离 ROI 更容易获得高追踪值的偏差。校正后的数值尤其不能解释为真实纤维数量，也不宜与采用不同处理流程的研究直接比较。

## 静息态功能连接

- **静息态 fMRI（resting-state fMRI）**：在受试者不执行特定任务时记录 BOLD 信号的自发波动。
- **BOLD 信号**：血氧水平依赖信号，是神经活动相关血流和血氧变化的间接测量，不是神经元放电的直接记录。
- **RSFC（resting-state functional connectivity）**：两个 ROI 的 BOLD 时间序列在统计上的共同变化，常以 Pearson 相关计算。
- **相关系数 `r`**：接近 `1` 表示正相关强，接近 `-1` 表示负相关强，接近 `0` 表示线性关系弱。
- **Fisher r-to-z 变换**：将相关系数转换为更适于跨受试者平均和统计检验的 z 值；该 z 值不是脑活动强度。

结构连接与功能连接反映不同层次：白质通路可为功能相互作用提供基础，但强 SC 不保证强 RSFC；强 RSFC 也可来自间接通路、共同输入或 DTI 难以识别的浅表皮层间纤维。

## 统计术语

- **P 值**：在原假设成立时，观察到当前或更极端结果的概率。`P < 0.05` 常被作为统计显著的阈值，但不表示结果为真的概率，也不表示效应一定重要。
- **多重比较校正**：同时进行很多检验会增加偶然显著的风险，因此需要调整阈值或 P 值。
- **ANOVA（方差分析）**：检验分组变量是否影响一个连续结果变量。
- **MANOVA（多变量方差分析）**：联合检验分组变量是否影响一组可能彼此相关的连续结果变量。例如，以性别为分组变量，同时检验多个脑区分区体积是否构成整体差异。

MANOVA 未显著只表示在当前样本和统计功效下，缺乏整体组间差异的证据；它不证明各组绝对相同。

## 结果解读检查表

- [ ] 区分 DWI 原始数据、DTI 模型结果与 tractography 衍生物。
- [ ] 不将 streamline 数、概率连接范围或 FA 当作真实轴突数量。
- [ ] 核对 ROI 定义、空间配准、bval/bvec 元数据和 DWI QC。
- [ ] 报告或阅读 SC 时确认追踪模型、阈值、距离校正和边权定义。
- [ ] 将 RSFC 表述为统计依赖，不表述为直接结构连接或因果影响。
- [ ] 解读 FA 时考虑交叉纤维、体素大小、模型局限和样本年龄范围。
- [ ] 对结构-功能关系报告效应量、统计校正与分析层级，不以单一指标作强因果解释。
