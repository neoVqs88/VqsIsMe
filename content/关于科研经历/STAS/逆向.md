下面给你一个**战术级操作流程**，保证能生成可用的 README。

---

## 🎯 正确投喂 AI 的步骤

### 第一步：让 AI 先理解项目结构
在 ChatGPT 或 Claude 里上传**整个文件夹的目录树**，然后问：

> “这是一个 Python 项目，没有 README，没有主入口注释。请分析这个目录结构，推测：
> 1. 项目的可能功能（从文件夹名、文件名猜）
> 2. 可能的启动入口文件是哪些（列出 Top 3）
> 3. 项目的模块划分（哪些是核心代码，哪些是工具，哪些是配置）”

**如何获得目录树**：在项目根目录执行
```bash
# Windows (PowerShell)
tree /F > structure.txt

# Mac/Linux
tree > structure.txt
```

---

### 第二步：分批喂代码，按优先级

不要一次全给，按这个顺序：

| 批次    | 内容                                                | 目标        |
| ----- | ------------------------------------------------- | --------- |
| **1** | 所有 `if __name__ == "__main__"` 的文件                | 找到启动入口    |
| **2** | 最大的几个 `.py` 文件（超过5KB的）                            | 理解核心逻辑    |
| **3** | 与比赛主题相关的文件（含“track”、“detect”、“train”、“model”等关键词） | 定位核心模块    |
| **4** | `utils.py`、`config.py`、`settings.py`              | 理解配置和工具函数 |
| **5** | 剩下的零散文件                                           | 补全细节      |

对每批，对 AI 说：

> “这是项目的 `[文件名]`，它是 Python 代码。请详细解释：
> - 这个文件的作用是什么（输入→处理→输出）？
> - 它依赖哪些其他模块（from/import）？
> - 主要的函数/类分别做什么？
> - 如果这个文件是主入口，它的程序执行流程是怎样的？”

---

### 第三步：让 AI 输出结构化 README

在所有文件分析完后，给 AI 这个指令：

> “基于前面我提供的所有文件分析，请为这个项目生成一份完整的 README.md，包括：
> 1. **项目名称与简介**（根据代码内容推测功能）
> 2. **环境要求**（Python 版本、主要依赖包——从 import 中提取）
> 3. **安装步骤**（虚拟环境创建 + pip install）
> 4. **运行方法**（明确指出主入口文件是哪个，给出命令行示例）
> 5. **核心模块说明**（每个主要文件的功能，一句话）
> 6. **输入/输出**（如果需要数据文件）
> 7. **已知问题/注意事项**（从代码中的 TODO、FIXME、异常处理推测）”

---

## ⚠️ 几个重要提醒

1. **不要直接说“帮我重写整个项目”**——AI 会生成泛泛的内容，且容易超过上下文
2. **敏感代码脱敏**：如果项目里有你们比赛的 API key、密码、私有数据路径，先删掉再喂
3. **多次对话**：用同一个 AI 对话窗口连续喂，它会记住前面的上下文
4. **Claude 比 ChatGPT 更擅长长文档分析**（如果你有账号的话）

---

## 🧰 替代方案（如果 AI 上下文限制太死）

用本地工具 **pydoc** 生成文档：

```bash
# 为整个项目生成 HTML 文档
pydoc -w ./
```

这会生成一堆静态 HTML 文件，虽然不够智能，但至少能看清函数签名和 docstring（如果有的话）。
