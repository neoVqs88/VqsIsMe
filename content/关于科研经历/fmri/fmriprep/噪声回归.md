## 🔬 CompCor：基于主成分的生理噪声去除

## 一、先解决你的核心困惑：128s cutoff是什么意思？

### 直观理解

想象你在听一首歌，里面有两种声音：

| 频率范围 | 周期 | 比喻 | 对应fMRI信号 |
|----------|------|------|-------------|
| **超低频** | >128秒 | 背景空调的嗡嗡声（很慢的变化） | 扫描仪漂移、呼吸缓慢变化 |
| **中频** | 几十秒 | 歌声的起伏 | **真正的神经活动** |
| **高频** | 几秒 | 鼓点的节奏 | 心跳、快速呼吸 |

**128s cutoff**的意思是：**把变化速度慢于128秒（即频率<0.0078 Hz）的成分滤掉**。

### 📊 可视化理解

```
原始fMRI信号随时间变化：
信号强度
   ↑
   │    ╭──╮    ╭──╮
   │   ╱    ╲  ╱    ╲    ← 中频成分（神经活动 ~0.01-0.1 Hz）
   │  ╱      ╲╱      ╲
   │ ╱                ╲
   │╱                  ╲
   ├──────────────────────→ 时间
   │    ────────慢变化────────  ← 超低频漂移（< 128s周期）
   
高通滤波（128s cutoff）后：
   │    ╭──╮    ╭──╮
   │   ╱    ╲  ╱    ╲        ← 只保留快于128s的成分
   │  ╱      ╲╱      ╲          （滤掉了超慢漂移）
   │ ╱                ╲
   │╱                  ╲
   ├──────────────────────→
```

### 为什么选128s？

| 考虑因素 | 说明 |
|----------|------|
| **生理节律下限** | 呼吸(0.2-0.5Hz)、心跳(1-1.5Hz)远快于0.0078Hz |
| **神经活动下限** | 任务fMRI中，block设计能低至0.01Hz |
| **漂移特征** | 扫描仪漂移、体温变化等超低频（0-0.005Hz） |
| **128s起源** | 经典文献认为约100-200s是漂移vs神经活动的分界点 |

## 二、CompCor的完整工作流程

### 第一步：为什么要做高通滤波？

```
问题：
┌────────────────────────────────────────────────┐
│ 我想从WM/CSF区域提取"噪声"                       │
│ 但WM/CSF中也混有神经活动（尤其是边界附近）        │
│ → 如果不做滤波，我的"噪声"成分里会包含神经信号    │
│ → 回归出去会损失真实信号（过于激进）             │
└────────────────────────────────────────────────┘

解决方案：
✅ 先高通滤波（128s cutoff）
✅ 滤掉超低频的神经活动成分
✅ 剩下的主要是：高频生理噪声 + 中频神经活动
✅ 然后PCA提取噪声 → 更安全
```

### 完整流程图

```
原始BOLD信号
    │
    ├──→ 高通滤波（128s cutoff）
    │    │
    │    ├── 滤掉：扫描仪漂移、体温变化
    │    └── 保留：神经活动 + 生理噪声
    │
    └──→ 分两条路
         │
         ├──→ aCompCor（基于解剖mask）
         │    │
         │    ├── 在结构像上定义WM和CSF区域
         │    ├── 投影到功能空间
         │    ├── 提取这些区域的时间序列
         │    ├── 对这些时间序列做PCA
         │    └── 取前k个主成分（解释50%方差）
         │
         └──→ tCompCor（基于功能数据）
              │
              ├── 全脑找变异最大的2%体素
              ├── 提取这些体素的时间序列
              ├── 对这些时间序列做PCA
              └── 取前k个主成分
```

## 三、aCompCor：解剖学定义的噪声

### 工作流程详解

#### Step 1: 在结构像上定义WM和CSF

```
T1w结构像 → FAST分割 → 概率图
                        ├── CSF概率（脑室、脑沟）
                        ├── GM概率（灰质）
                        └── WM概率（白质）

aCompCor取：
- CSF区域（概率>0.99，非常严格）
- WM区域（概率>0.99）
- 组合区域（CSF+WM）
```

#### Step 2: 投影到功能空间

```
高分辨率结构像WM mask        低分辨率功能像WM mask
┌─────────────────┐          ┌─────────────┐
│ ███████████████ │          │ ░░███░░░███░│
│ ███████████████ │ ──配准→  │ ████████████│
│ ███████████████ │          │ ░░░░░░░░░░░░│
│ ███████████████ │          │ ░██░████░██░│
└─────────────────┘          └─────────────┘
    (1mm)                         (3mm)
         ↑
   用已经算好的T1→功能配准矩阵（bbregister的结果）
```

#### Step 3: 提取时间序列

```python
# 对于WM mask中的每个体素
for each voxel in WM_mask:
    time_series = BOLD[voxel, :]  # 形状: (时间点数,)
    
# 结果是 WM_timecourses 矩阵: (体素数, 时间点数)

# 然后对WM_timecourses做PCA
```

#### Step 4: PCA降维

```
假设有500个体素（功能空间的WM区域）
时间点数 = 300

原始数据：500 × 300 矩阵

PCA分解后：
主成分1: 解释60%方差 ──→ 最强的噪声模式（可能是心跳）
主成分2: 解释15%方差 ──→ 第二强（可能是呼吸）
主成分3: 解释8%方差  ──→ 第三强
主成分4: 解释5%方差
...
主成分k: 累积解释≥50%方差（通常k=5-6）

最终用这k个主成分作为噪声回归量
```

### 为什么用PCA而不是简单平均？

| 方法 | 优点 | 缺点 |
|------|------|------|
| **简单平均** | 简单、快 | 平均会丢失信息，不同区域噪声不同 |
| **PCA** | 保留差异，自动选"最强"噪声 | 复杂、慢 |

**直观比喻**：
- 简单平均：对100个人问"平均感受"，可能掩盖个体差异
- PCA：先找100人中最有代表性的几种"原型"，用它们代表整体

## 四、tCompCor：时间序列定义的噪声

### 工作流程

#### Step 1: 找出最"活跃"的体素

```python
# 计算每个体素的时间序列标准差
voxel_std = std(BOLD, axis=time)  # 每个体素一个值

# 找标准差最高的2%体素
threshold = percentile(voxel_std, 98)  # 前2%
high_var_voxels = where(voxel_std > threshold)
```

#### Step 2: 为什么找高方差的体素？

```
假设逻辑：
- 方差的来源：神经活动 + 生理噪声
- 生理噪声在全脑普遍存在（血管、脑室周围）
- 神经活动只在特定区域

问题：高方差体素里既有神经活动，也有生理噪声！
所以tCompCor在理论上不如aCompCor纯净

这也就是为什么：
✅ aCompCor：基于结构（已知WM/CSF是噪声区域）
⚠️ tCompCor：基于统计（可能混入灰质体素）
```

#### Step 3: PCA和成分选择

```
高方差体素：~100个体素（假设全脑5000体素 × 2% = 100）
时间点数：300

tCompCor主成分：同样方法，取到累计解释50%方差为止
```

## 五、aCompCor vs tCompCor 对比

| 维度 | aCompCor | tCompCor |
|------|----------|----------|
| **定义方式** | 解剖先验（WM/CSF） | 统计高变异体素 |
| **受神经活动污染** | 很少（WM/CSF几乎无神经） | 可能（灰质体素也在高变异中） |
| **个体差异** | 依赖分割质量 | 依赖功能数据质量 |
| **使用建议** | **首选**，更安全 | 作为补充或替代 |

**fMRIPrep的做法**：两种都计算，都输出confounds文件，让用户自己选择。

## 七、CAPs论文中的做法

回顾你提供的CAPs论文原文：

> the brain-averaged signal, the time series of regions of interest in the white matter and cerebrospinal fluid, and six affine motion parameters were regressed out

**他们没有用CompCor！** 他们用的是：
- 简单平均：WM信号的平均
- 简单平均：CSF信号的平均
- 全局信号

所以fMRIPrep的CompCor是一个**更先进但不同的方法**。

### 对于CAPs复现，你有两个选择：

| 选择 | 做法 | 优缺点 |
|------|------|--------|
| **A：严格复现** | 从fMRIPrep输出中提取WM/CSF mask，计算简单平均，而不是用CompCor | ✅ 与论文一致<br>❌ 可能非最优 |
| **B：采用CompCor** | 直接使用fMRIPrep输出的aCompCor成分 | ✅ 更先进<br>⚠️ 需要论证合理性 |

## 八、实际操作建议

### 如果你要复现CAPs论文的做法

```python
from nilearn import image, masking
from nilearn.interfaces.fmriprep import load_confounds

# 不要用load_confounds的compcor策略
# 而是自己提取mask和计算平均

# 加载fMRIPrep生成的WM和CSF mask
wm_mask = image.load_img('sub-01_space-MNI152NLin2009cAsym_label-WM_probseg.nii.gz')
csf_mask = image.load_img('sub-01_space-MNI152NLin2009cAsym_label-CSF_probseg.nii.gz')

# 阈值化（如>0.99）
wm_bin = image.math_img('img > 0.99', img=wm_mask)
csf_bin = image.math_img('img > 0.99', img=csf_mask)

# 提取平均时间序列
wm_signal = masking.apply_mask(func_img, wm_bin).mean(axis=0)
csf_signal = masking.apply_mask(func_img, csf_bin).mean(axis=0)

# 然后回归掉这些平均信号 + 运动参数
```

### 如果你要采用CompCor（更推荐）

```python
# 直接用load_confounds加载aCompCor成分
confounds = load_confounds(
    'sub-01_task-rest_bold.nii.gz',
    strategy=['motion', 'compcor'],
    compcor='anat_combined',  # WM+CSF组合
    n_compcor=5  # 使用前5个成分
)

# 然后clean_img会自动回归这些成分
```

## 🎯 总结

| 概念 | 核心要点 |
|------|----------|
| **128s cutoff** | 高通滤波的阈值，滤掉慢于128秒的成分（漂移） |
| **为什么滤波** | 防止噪声回归时误伤神经信号 |
| **aCompCor** | 在解剖定义的WM/CSF区域做PCA |
| **tCompCor** | 在高变异体素中做PCA（较少用） |
| **为什么用PCA** | 自动提取"主要"噪声模式，比简单平均更精准 |
| **对CAPs的影响** | 论文用简单平均，你用CompCor可能更好但需说明差异 |
