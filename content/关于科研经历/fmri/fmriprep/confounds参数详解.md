## 📊 FD和DVARS：fMRI质量控制的"仪表盘"

## 核心概念理解

想象你在**拍一段视频**，但相机在晃动：

| 概念 | 通俗理解 | fMRI对应 |
|------|----------|----------|
| **FD** | 相机**物理移动了多少** | 你头的位移/旋转 |
| **DVARS** | 画面**突然变化了多少** | 全脑信号突变 |

**一句话**：FD看**头移了多少**，DVARS看**信号跳了多少**。两者结合，找出"这个时间点数据不能要"的volume。

---

## 🔴 第一个指标：FD (Framewise Displacement)

### 定义
**头动的"距离"度量**——你的头在这个时间点相对于上一个时间点移动了多少。

### 两种计算方式（论文同时报告两种）

| 方法 | 计算逻辑 | 物理意义 | 典型阈值 |
|------|----------|----------|----------|
| **Power FD** | 6个运动参数的**绝对值之和** | 综合位移+旋转的"总移动量" | **0.2-0.5mm** |
| **Jenkinson FD** | 仿射矩阵的**RMS位移** | 更精确的刚体运动度量 | 同左 |

### 📐 Power FD的计算公式（简化版）

```
Power FD = |Δx| + |Δy| + |Δz| + (50 × |Δα|) + (50 × |Δβ|) + (50 × |Δγ|)
           └─平移(mm)─┘   └─────────旋转换算成mm─────────┘

其中：
- Δx, Δy, Δz = 平移变化（mm）
- Δα, Δβ, Δγ = 旋转变化（弧度），乘以50是因为旋转1弧度≈在50mm半径上的位移约50mm
```

### 实际例子

```
Volume 1 → Volume 2 的运动参数变化：
Δx = 0.1mm, Δy = 0.05mm, Δz = 0.08mm
Δα = 0.002弧度, Δβ = 0.001弧度, Δγ = 0.003弧度

Power FD = (0.1+0.05+0.08) + 50×(0.002+0.001+0.003)
        = 0.23 + 50×0.006
        = 0.23 + 0.3
        = 0.53 mm  ← 超过通常的0.5mm阈值
```

## 🔵 第二个指标：DVARS

### 定义
**全脑信号的"突变"度量**——整个大脑的BOLD信号从上一帧到这一帧变化了多少。

### 公式解析

```
DVARS(t) = RMS( ΔBOLD(t) )
          └─────┬─────┘
         全脑体素BOLD信号的变化量（一阶差分）的均方根

通俗理解：计算所有体素的"从上帧到这帧变亮/变暗了多少"，然后取平均值
```

### 实际例子

```
某个体素的BOLD信号变化：
Frame 1: 1000
Frame 2: 1200  ← 增加了200（可能是生理噪声/头动/真实信号）
          ↑
    DVARS会在Frame 2把这个变化计入

平均全脑所有体素的变化 → DVARS值
```

### 📊 DVARS的两种常见表现形式

fMRIPrep报告中通常有两种展示：

| 形式 | 展现 | 用途 |
|------|------|------|
| **原始DVARS** | 绝对数值 | 质量评估 |
| **标准化DVARS** | 除以时间序列的SD | **跨被试比较**（论文常用） |

### 标准化DVARS示例

```
Volume之间的SVARS（去均值后）：
Frame 1: 0.8
Frame 2: 1.6 ← 超过1.5阈值（异常）
Frame 3: 0.9
Frame 4: 2.1 ← 超过2.0（严重异常）
          ↑
    通常阈值：1.5（中等严格）或2.0（宽松）
```

## 🎯 FD和DVARS的协同使用

### 为什么需要两个指标？

| 情况 | FD | DVARS | 判断 | 例子 |
|------|----|----|------|------|
| **物理头动** | 高 | 高 | ❌ 异常 | 打哈欠、调整姿势 |
| **生理噪声** | 低 | 高 | ⚠️ 可能异常 | 深呼吸、心跳突变 |
| **扫描仪故障** | 低 | 高 | ❌ 异常 | 射线管闪烁 |
| **正常波动** | 低 | 低 | ✅ 正常 | 安静休息 |

### 组合使用策略

```
异常判断逻辑：
IF FD > 0.5mm OR DVARS > 1.5 THEN 标记为"坏帧"

实际操作中：
- 严格标准：FD > 0.2mm OR DVARS > 1.0 → censor
- 标准标准：FD > 0.5mm OR DVARS > 1.5 → censor（CAPs论文常用）
- 宽松标准：FD > 1.0mm OR DVARS > 2.0 → censor
```

## 🔧 你应该如何处理这些指标？

### 在CAPs分析中推荐的做法

```python
# 1. 第一步：读取fMRIPrep输出的confounds
import pandas as pd
confounds = pd.read_csv('sub-01_confounds.tsv', sep='\t')

# 2. 第二步：创建censor向量（1=保留，0=剔除）
fd_threshold = 0.5  # mm
dvars_threshold = 1.5  # 标准化DVARS

good_frames = (confounds['framewise_displacement'] < fd_threshold) & \
              (confounds['std_dvars'] < dvars_threshold)

# 3. 第三步：决定如何处理异常帧
```

### 三种常见策略

| 策略 | 方法 | 适用场景 | 数据损失 |
|------|------|----------|----------|
| **1. Censoring** | 直接删除异常帧 | 异常帧<15% | 中等 |
| **2. 回归** | 把异常帧作为哑变量回归掉 | 异常帧较多 | 较低 |
| **3. 不做处理** | 保持原样 | 异常帧<5% | 无 |

### CAPs论文的标准做法

根据Original CAPs论文，他们的做法是：

```
步骤1：计算FD（Power）和DVARS
步骤2：移除FD > 0.5mm 或 DVARS > 1.5 的volume
步骤3：只保留连续至少5个volume的数据段（用于后续分析）
步骤4：报告剩余有效volume数
```

## 💡 最关键的一点

fMRIPrep**只是帮你计算了这些指标**和**标记了异常帧**（motion_outlier列），但**并没有自动剔除它们**！

你需要自己决定：
1. 用什么阈值？
2. 剔除还是回归？
3. 是否要求连续帧？

**这就是为什么预处理只是第一步，质量控制需要你自己做。**
