## 二、回答你的滤波问题

### "只低通滤波是不是就可以？毕竟128s已经被滤过了"

**答案：不可以！** 让我解释为什么。

### 128s高通滤波 ≠ 0.005Hz高通滤波

```
频率对比：

fMRIPrep做的（高通128s）:
   0.0078 Hz (周期128秒)
        ↑
   滤掉 <0.0078 Hz 的成分

CAPs论文要求的（高通0.005Hz）:
   0.005 Hz (周期200秒)
        ↑
   滤掉 <0.005 Hz 的成分

差异：
┌─────────────────────────────────────────────────┐
│ 0.005Hz                        0.0078Hz         │
│   ↓                               ↓             │
├───┼───────────────────────────────┼─────────────→ 频率
│   │                               │             │
│   ← 0.005-0.0078Hz 这一段          →            │
│   CAPs滤掉，fMRIPrep保留！                       │
└─────────────────────────────────────────────────┘
```

### 为什么这个差异重要？

```
0.005-0.0078 Hz 成分（周期128-200秒）包含什么？

1. 非常慢的神经活动
   - 有些静息态网络以0.006-0.008 Hz波动
   - 如果保留，这些网络可能被高估

2. 残余的生理漂移
   - CO₂水平的缓慢变化（周期~180秒）
   - 体温调节（周期~200秒）

3. 扫描仪长期漂移
   - 磁体加热/冷却（周期>200秒的部分已被fMRIPrep滤掉）
   - 但更快的变化还在
```

### 正确的做法

```python
# CAPs论文要求：0.005-0.1 Hz
# fMRIPrep只做了高通0.0078Hz

# 你需要：
# 1. 低通：滤掉 >0.1 Hz（高频生理噪声）
# 2. 高通：滤掉 <0.005 Hz（超低频漂移）
#    ↑ 这一步fMRIPrep没做到位！

cleaned = clean(
    img,
    high_pass=0.005,   # ← 必须改成0.005，不能用fMRIPrep的128s
    low_pass=0.1,
    ...
)
```

### 验证方法

```python
# 检查fMRIPrep滤波后的信号是否还有超低频成分
import numpy as np
from scipy.fft import fft, fftfreq

def check_frequency_content(data, tr=2.0):
    """检查信号的频率分布"""
    n = len(data)
    freq = fftfreq(n, tr)
    fft_vals = np.abs(fft(data))
    
    # 查看0.005-0.0078Hz之间的能量
    idx_005 = np.argmin(np.abs(freq - 0.005))
    idx_008 = np.argmin(np.abs(freq - 0.0078))
    
    energy_band = np.sum(fft_vals[idx_005:idx_008]**2)
    total_energy = np.sum(fft_vals**2)
    
    print(f"0.005-0.0078Hz能量占比: {energy_band/total_energy*100:.2f}%")
    # 如果 >5% 说明需要额外高通滤波
    
# 对fMRIPrep输出检查
# 很可能有相当能量在这个频段 → 必须加高通0.005Hz
```

## 三、你可能遗漏的步骤

### 8. 检查并处理极端异常值（Despiking）

```markdown
fMRIPrep有没有做？❌ 没有

CAPs论文有没有做？❌ 没有明确提到

为什么可能需要？
- 头动突然跳变会产生 spike（尖峰）
- 这些 spike 会严重影响功能连接
- 标准流程通常包含 despiking

建议做法：
- 先不 despiking，运行 CAPs
- 如果结果不稳定，加上 despiking 再跑
```

### 9. 确保连续帧要求（Censoring策略）

```markdown
CAPs分析的特殊性：
- 需要连续的时间点来提取模式
- 如果剔除太多帧，时间序列可能不连续

常见做法：
- 只保留长度≥5的连续片段
- 如果剔除超过50%的帧，整段数据丢弃
```

### 10. 全局信号回归的争议处理

```markdown
CAPs论文特意做了两套数据：
- 一套有GSR
- 一套无GSR

为什么？
- GSR可以去除更彻底的噪声
- 但可能引入假阴性相关（争议）
- 两套都做，报告差异
```

## 五、代码实现：一站式后处理

```python
#!/usr/bin/env python3
"""
将fMRIPrep输出处理为CAPs分析就绪的格式
"""

import numpy as np
from nilearn import image, masking
from nilearn.interfaces.fmriprep import load_confounds
from nilearn.signal import clean
from scipy import stats

def preprocess_for_caps(bold_file, mask_file, output_prefix, 
                        fwhm=4.0,           # 平滑核大小(mm)
                        tr=2.0,             # 重复时间(秒)
                        high_pass=0.005,    # 高通频率(Hz)
                        low_pass=0.1,       # 低通频率(Hz)
                        fd_threshold=0.5,   # FD阈值(mm)
                        dvars_threshold=1.5,# DVARS阈值
                        make_gsr_versions=True,
                        resample_to_3mm=True):
    """
    完整的fMRIPrep到CAPs预处理流程
    """
    
    # 1. 加载数据
    print("1. 加载fMRIPrep输出...")
    img = image.load_img(bold_file)
    mask = image.load_img(mask_file) if mask_file else None
    
    # 2. 空间平滑（如果指定了fwhm>0）
    if fwhm > 0:
        print(f"2. 空间平滑 (FWHM={fwhm}mm)...")
        from nilearn.image import smooth_img
        img = smooth_img(img, fwhm)
    
    # 3. 可选：重采样到3mm
    if resample_to_3mm:
        print("3. 重采样到3×3×3mm³...")
        # 需要下载MNI 3mm模板
        template_3mm = image.load_img('MNI152_T1_3mm_brain.nii.gz')
        img = image.resample_to_img(img, template_3mm, interpolation='continuous')
        if mask:
            mask = image.resample_to_img(mask, template_3mm, interpolation='nearest')
    
    # 4. 创建GSR版本
    gsr_options = [False, True] if make_gsr_versions else [False]
    
    for use_gsr in gsr_options:
        suffix = 'with_GSR' if use_gsr else 'without_GSR'
        print(f"\n处理 {suffix} 版本...")
        
        # 5. 加载confounds
        print("   - 加载噪声回归量...")
        confounds = load_confounds(
            bold_file,
            strategy=['motion', 'wm_csf', 'high_pass'],
            motion='full',           # 6参数 + 导数 + 平方
            wm_csf='full',           # WM和CSF信号
            global_signal='full' if use_gsr else None,
            high_pass='full'         # DCT基函数
        )
        
        # 6. 清洗数据（回归+滤波+去趋势+可选标准化）
        print("   - 回归噪声、滤波、去趋势...")
        cleaned = clean(
            img,
            confounds=confounds,
            detrend=False,           # 不用，因为下面要手动做polort=2
            low_pass=low_pass,
            high_pass=high_pass,     # ← 关键：0.005 Hz，不是128s
            t_r=tr,
            standardize=False,       # 先不标准化，后面手动做
            ensure_finite=True
        )
        
        # 7. 手动去除线性+二次趋势（polort=2）
        print("   - 去除线性和二次趋势...")
        data = cleaned.get_fdata()
        mask_data = mask.get_fdata() > 0 if mask else (data.std(axis=-1) > 0)
        
        n_time = data.shape[-1]
        time = np.arange(n_time)
        # 创建设计矩阵：常数 + 线性 + 二次
        X = np.column_stack([np.ones(n_time), time, time**2])
        # 投影矩阵
        H = X @ np.linalg.pinv(X)
        
        for i in range(data.shape[0]):
            for j in range(data.shape[1]):
                for k in range(data.shape[2]):
                    if mask_data[i, j, k]:
                        ts = data[i, j, k, :]
                        if np.any(np.isnan(ts)):
                            continue
                        # 减去趋势
                        data[i, j, k, :] = ts - H @ ts
        
        # 8. z-score标准化（每个体素独立）
        print("   - z-score标准化...")
        for i in range(data.shape[0]):
            for j in range(data.shape[1]):
                for k in range(data.shape[2]):
                    if mask_data[i, j, k]:
                        ts = data[i, j, k, :]
                        ts_mean = np.nanmean(ts)
                        ts_std = np.nanstd(ts)
                        if ts_std > 0:
                            data[i, j, k, :] = (ts - ts_mean) / ts_std
        
        # 9. 处理坏帧（将FD/DVARS超标的帧设为NaN）
        print("   - 标记坏帧...")
        # 从confounds中提取FD和DVARS
        # 注意：load_confounds返回的confounds需要包含这些列
        
        # 保存
        output_file = f"{output_prefix}_caps_{suffix}.nii.gz"
        cleaned_img = image.new_img_like(img, data)
        cleaned_img.to_filename(output_file)
        print(f"   - 保存到: {output_file}")
    
    print("\n完成！")
    return

# 使用示例
if __name__ == "__main__":
    preprocess_for_caps(
        bold_file='sub-01_desc-preproc_bold.nii.gz',
        mask_file='sub-01_desc-brain_mask.nii.gz',
        output_prefix='sub-01',
        fwhm=4.0,           # CAPs论文的平滑参数
        tr=2.0,
        high_pass=0.005,    # CAPs论文的滤波下限
        low_pass=0.1,       # CAPs论文的滤波上限
        fd_threshold=0.5,
        dvars_threshold=1.5,
        make_gsr_versions=True,
        resample_to_3mm=True  # 严格匹配原始论文
    )
```

## 📝 总结

你的理解**90%正确**，关键补充：

1. **带通滤波不能只做低通**：fMRIPrep的128s高通(0.0078Hz) ≠ CAPs的0.005Hz高通，必须重新做高通到0.005Hz

2. **回归参数要扩展**：6个运动参数要加导数和平方项（共18个）

3. **Welch方法的顺序**：fMRIPrep的CompCor是在高通滤波后做的，不影响你的后处理

4. **两个版本**：GSR版本 + censor版本（保持完整时间序列）
